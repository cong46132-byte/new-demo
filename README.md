# 好财 · 库存与采购申请管理系统

基于 Vue 3 + Vite + Element Plus 的静态演示项目，无需后端和数据库。覆盖物品档案、采购及退货入库、库存调整、领用审批与出库、批量采购申请与审批、采购处理与分批到货、库存预警、库存流水及筛选统计。

## 运行

```bash
npm install
npm run dev
```

在浏览器中打开终端显示的本地地址（默认 `http://localhost:5173`）。

## 静态交付

```bash
npm run build
```

将生成的 `dist/` 目录部署到任意静态网站托管服务即可在线演示。若要在本机预览构建产物，运行 `npm run preview`。建议通过 HTTP 服务打开，不要直接以 `file://` 打开 HTML：浏览器可能不允许该地址使用本地存储。

## 推荐演示路径

1. 在「库存预警」对低库存物品创建采购申请。
2. 切换到普通员工，在「采购申请」保存草稿并提交；切换到同部门负责人审批，进入「采购处理」查看自动生成的任务。跨部门负责人无法审批。
3. 切换到采购人员填写采购信息，分两次登记实际到货；检查库存和采购状态是否相应更新。
4. 切换到普通员工发起领用，再切换到仓库管理员审核（锁定可用库存）并执行出库。可从已出库领用单直接登记退回，退回数量不能超过未退数量。
5. 在「库存记录与统计」按物品、部门、分类、时间及操作类型检索流水。
6. 通过右上角切换演示角色，或点击重置按钮恢复初始演示数据。

后台常用操作：顶部全局搜索可查物品、采购申请与采购任务，支持 `Ctrl/⌘ + K` 或 `/` 快捷打开；各列表筛选栏可一键重置；库存记录可按当前筛选条件导出带 UTF-8 BOM 的 CSV，便于在 Excel 中直接打开中文内容。

右上角「外观」支持浅色／深色模式、标准蓝／紫罗兰／青蓝主题色和舒适／紧凑显示密度。外观设置会单独保存，重置演示业务数据不会清除皮肤偏好。

数据保存在当前浏览器的 `localStorage` 中；角色切换用于演示前端角色与部门操作限制，不提供真实登录鉴权、跨浏览器数据同步或服务端存储。临期预警按剩余库存批次计算；升级前已保存的数据会迁移为“历史库存”批次，若要体验完整的预置批次数据，可在页面右上角重置演示数据。
